Politique de confidentialité

Dernière mise à jour : 4 mai 2026

Données collectées

CultureFlash collecte uniquement les données nécessaires au fonctionnement de l’application : profil utilisateur, réponses quotidiennes, streak, progression et statut d’abonnement.

Services tiers

  • Supabase pour l’authentification et la base de données.
  • RevenueCat pour la gestion des abonnements.
  • Expo Notifications pour les rappels locaux.
  • Open Trivia DB pour les questions de quiz.

Partage des données

CultureFlash ne vend pas les données personnelles. Les données peuvent être traitées par les services tiers listés ci-dessus pour fournir les fonctionnalités de l’application.

Contact

Pour toute demande d’accès, de correction ou de suppression des données, contactez le propriétaire du projet via GitHub.
